# Onboarding Your Team

Use the **Nomos Agent** to submit a structured onboarding request. It validates team data and proposes changes through pull requests in the repositories that own each capability.

## Build Your Agent Prompt

:::tip[You have all the details]

Fill in the form, select **Copy**, and paste the result into Nomos. The agent confirms the requested scope and opens the required pull request or pull requests. Toggle **Optional** for cloud, workflow, database, and Kubernetes capabilities.

:::

## How to Invoke the Agent

<InvocationTabs>
  <InvocationPanel value="cli">
    <p style={cardTitle}>Copilot CLI</p>
    <p style={{...cardBody, marginBottom: '0.75rem'}}>With Docker available, install the plugin, set <code>NOMOS_GITHUB_TOKEN</code>, and start Copilot CLI:</p>
    <pre style={{fontSize: '0.8rem', margin: 0}}>{'copilot plugin marketplace add osinfra-io/pt-ai-plugins\ncopilot plugin install techne-agents@osinfra-io\nprintf \'NOMOS_GITHUB_TOKEN: \'\nread -rs NOMOS_GITHUB_TOKEN\nprintf \'\\n\'\nexport NOMOS_GITHUB_TOKEN\ncopilot --enable-all-github-mcp-tools'}</pre>
    <p style={{...cardBody, marginTop: '0.5rem'}}>Type <code>/agent</code>, select <strong>Nomos Agent</strong>, and paste your prompt. The plugin registers its version-pinned MCP server automatically.</p>
  </InvocationPanel>
  <InvocationPanel value="github">
    <p style={cardTitle}>GitHub UI</p>
    <p style={cardBody}>Navigate to <a href="https://github.com/osinfra-io/pt-techne-agents/agents" target="_blank" rel="noopener noreferrer">pt-techne-agents/agents</a> on GitHub, select the <strong>Nomos Agent</strong>, and paste your prompt. The agent opens a PR automatically.</p>
  </InvocationPanel>
  <InvocationPanel value="vscode">
    <p style={cardTitle}>VS Code</p>
    <p style={cardBody}>Open <code>pt-techne-agents</code> in VS Code, start a Copilot Chat session, type <code>/agent</code>, select <strong>Nomos Agent</strong>, and paste your prompt.</p>
  </InvocationPanel>
</InvocationTabs>

:::tip GitHub access

The agent opens pull requests through the GitHub MCP server. In Copilot CLI, start with `--enable-all-github-mcp-tools` so write tools are available; no separate GitHub token is needed. `NOMOS_GITHUB_TOKEN` above is only for the Nomos plugin's own MCP server.

:::
